## DP-1 元素参数包：把法术引擎从 switch 手写改成数据驱动（含 UGC 出口）

**动机**：审计证实"9×5×5×5"矩阵大面积空转（debuff 九元素同一行为、utility 七元素纯粒子、
修饰词对 4/5 形式 no-op）。手写 switch 填不满 1125 个组合，填满也不可维护。

**设计**：三轴正交化。
- **元素 = 参数包**（json，`data/qianxiang/spell_elements/*.json`）：
  ```json
  {
    "damage_type": "minecraft:fire",          // 伤害标签/类型
    "particle": "minecraft:flame",
    "sound_cast": "minecraft:entity.blaze.shoot",
    "on_hit_effects": [{"id":"minecraft:slowness","duration":60,"per_power":20}],
    "debuff_effects": [...],                   // debuff 效果专用表——九元素从此分化
    "utility_action": "ignite_block",          // 枚举钩子:点燃/结冰/骨粉/传送/照明…
    "buff_effect": "minecraft:fire_resistance",
    "tint": "#FF6A00"
  }
  ```
- **形式**只负责送达（弹体/自身/AOE/射线/触碰），**效果**只负责命中后做什么——两者读元素
  参数包取参数，不再 switch 元素。
- **修饰词 = 装饰器**，对每种形式都定义语义：homing 对 aoe=中心追踪目标移动、chain 对任意
  元素=换传导粒子、piercing 对 beam=穿透方块一格。
- UGC：datapack 放一个新 json 就是一个新元素，AI prompt 的元素白名单从注册表动态生成。

**实施要点**：SpellEffectEngine 重构为 `ElementPack` 查表 + 五个形式管线；现有 9 元素行为
先原样翻译成 9 个 json（行为不回退）；`CustomSpell` 白名单改从 ElementPack 注册表取。
**影响面**：spell/ 包大改，网络协议不动，存档兼容（element 字符串不变）。约 2~3 天。
**优先级建议**：里程碑二主体，WQ-8/9 之后。

## DP-2 统一"强度预算"经济：powerScore 成为唯一货币

**动机**：武器轨强度由材料 powerScore 决定且有代价机制（超阈值触发 frail/heavy 等），
法术轨在 WQ-1 修复后也将有材料上限——但两轨仍是两套账本，AI 的自由效果段还是第三套。

**设计**：锻造时算出**总预算 = Σ材料 powerScore**，产物的一切数值消费同一预算：
攻击/护甲/耐久按现有 AttributeScheme 分配；法术 power 每级消费固定预算；AI 自由效果按
效果词典标价。预算不足 → AI 必须做取舍（这正是"AI 当配方大脑"的趣味来源）；
玩家主动**超支**→ 显式选择一个代价（现有 DrawbackRules 从"惩罚"变"交易"，玩家自选
frail/heavy/draining 之一换取超支额度）。
**为什么值得**：把"强度靠材料"从两条平行规则变成一条经济学；"代价"从暗坑变成 build
决策点；AI prompt 也简化——告诉它预算和价目表，让它做分配题而不是自由发挥。
**实施要点**：AttributeScheme 加 budget 结算层；ForgeComposer 把预算传入 AI prompt 与
spell 钳制；DrawbackRules 加"自选代价换额度"入口（锻造台 UI 一个下拉）。约 2 天。

## DP-3 AI 输出"选择题化" + 采纳数据飞轮

**动机**：小模型（qwen2.5:7b）自由生成 JSON 容易越界/幻觉材料 id；同时 qianxiang-ai.jsonl
已在记录 AI 交互——这是没被利用的数据资产。

**设计**：
1. **选择题化**：prompt 不再让 AI 自由写配方，而是服务端先按关键词/算子粗筛出 15~30 个
   候选材料，AI 只做"从候选里选 N 个 + 分配预算 + 起名"。输出空间小 → 小模型成功率高、
   token 省一半、解析失败率降。
2. **采纳飞轮**：jsonl 里补记"玩家最终采纳了哪个方案/有没有改动"；累计后可以：
   ①把高采纳率的 AI 配方沉淀为新的 FallbackRecipes 条目（兜底库自动成长）；
   ②做 /qianxiang ai eval 离线评估脚本，换模型/改 prompt 前后对比采纳率。
**实施要点**：与 WQ-2（索引回传）同一次协议改动里做，采纳事件在锻造成功处埋点。
**影响面**：ai/ 包为主。飞轮部分零玩法风险，纯增量。

## DP-4 终局二段：位格深潜与"残界"

**动机**：WQ-6 落地后进程链闭合于"用核锻传奇"，但传奇装备没有用武之地；位格系统
（已接门控）只有一道 3 级门槛；万象森罗充实后仍是单层世界。

**设计**（低成本版，全部复用现有机制）：
- **残界**：不做新维度——在万象森罗 y<0 的深层放置"深渊裂隙"（复用裂隙岩+新 biome 或
  仅结构），进入需**位格 ≥ 10**（位格系统第二道门，逼玩家积累锻造/击杀/交易履历）。
- 深层刷新**守望者·残响**（现有 Boss 换名+数值 1.5x+技能频率翻倍，代码级零新增美术），
  掉落"残响之核"——用于把现有装备**重铸升华**（锻造台放入成品+核=数值上浮+一条新词条，
  这给了锻造台第二用途：不只造新的，还改旧的）。
- 相谱在位格 10/25/50 时自动铭刻"位格试炼"条目，`/qianxiang saga` 变成真正的进度书。
**实施要点**：重铸 = ForgeComposer 加"成品+核"识别分支；残界结构复用 WQ 的 RiftRuinFeature
管线。约 3 天。**这是让"传奇之后还有目标"的最便宜路径。**

## DP-5 NPC 从商贩升级为"价值观任务发生器"

**动机**：两个 NPC 的价值观定价是全项目最有个性的设计，但只作用于价格；对话只有 3 句；
交易表硬编码（已有工单）。

**设计**：让价值观产生**任务**而不只是折扣——
- 相师（厌恶屠杀）：给"净化委托"——去万象森罗不杀生存活 N 分钟 / 用 heal 法术治疗 NPC，
  奖励稀有材料+外交烙印；对屠夫玩家拒绝委托并涨价（现有机制）。
- 深渊商人（欣赏强者）：给"猎杀契约"——猎杀指定强化怪（普通怪+发光+数值 buff，运行时
  生成不需要新实体），奖励绿宝石+屠杀烙印。
- 两条任务线**互斥消长**（接一边掉另一边好感），把"你的行为塑造价格"升级为
  "你的价值观塑造玩法路线"。委托数据 datapack 化（与交易表迁移同一批做）。
**实施要点**：一个轻量委托组件挂玩家 attachment（当前委托 id+进度+期限），事件钩子复用
FactionEventHandler；对话由委托状态驱动（接单/进行中/交付三句 × 两 NPC）。约 2~3 天。

## DP-6 锻造台的"手感"层：让核心交互配得上核心地位

**动机**：锻造台是整个 mod 的舞台，但审计显示它的反馈层薄：产物是"点了就出"，AI 等待
是干等（现在还有卡 PARSING 的 bug 在修），失败提示是聊天刷屏（"当前材料无法锻造成器"
一次会话十几条）。

**设计**（纯客户端/表现层，不动数值）：
- 锻造出品加 0.5~1 秒的锻打动画序列（GUI 内进度条+3 声 ANVIL 敲击+粒子，产物揭晓感）；
- AI 思考时显示滚动的"相性推演"文本（从材料 functions 随机拼词，纯演出）而非静止等待；
- 无法成器时在产物槽画灰色问号+tooltip 列出"缺什么"（缺基底算子/缺功能算子——
  ForgeComposer 的拒绝原因目前被丢弃，透出来即可），替代聊天刷屏；
- 材料放入时按相性给槽位边框着色（火系橙框/冰系蓝框），教学零文字化。
**实施要点**：ForgeComposer 拒绝时返回原因枚举（现在只返回 invalid）；其余全在
ForgeTableScreen。约 1~2 天，体验提升与工作量比全项目最高。
