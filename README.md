# 牵响 Qianxiang

> 告诉 AI 你想要什么,它帮你找材料,你来锻造。

NeoForge 1.21.1 模组。核心理念:**材料即零件,AI 当配方大脑,强度靠材料**。

## 核心玩法

1. **相锻造** — 锻造台不吃固定配方。材料不用摆格子:**手持右键投进台子**(潜行投整组,扔到台面上也会被吸收),台面上方漂浮材料虚影实时可见,潜行+空手右键取回全部材料;GUI 里**左键背包物品=投入 1 个、Shift=整组**,**材料行左键=取回 1 个、Shift=全取**,材料区标题旁有「全部取回」按钮。**填充顺序即布局**:投料从中心向外,第一个料永远落在中心核心槽;布局一次推导武器**形态**(9 种:剑/巨剑/匕首/太刀/长枪/战斧/重锤/镰刀/钉锤),外观纹理、EF 动作底座、攻击判定盒统一随形态走;外观为 **32×32 程序化手绘贴图**(深色描边+清晰剪影+分段色阶,13 张形态模板逐张手绘,刃体三档色阶),武器颜色=核心材料身体(钢灰/象牙白/深棕/革棕)+主导效果刃缘,手持为按形态挤出的 3D 几何。产物就绪后点「开始创作」(产物槽/空手右键同效)触发**合成仪式**:GUI 关闭,材料飞入台中化为粒子——炼金台在空中画出双层反向魔法阵,锻造台则是锻打火花——仪式完成后产物留在台面,空手右键拾取。原版物品也是零件,产物属性完全由材料的品阶、相性、功能算子决定(最多 25 件,超过 10 件的零件强度分按半权重计入,防线性膨胀)。GUI 保留 AI 推荐/蓝图面板(去网格,材料区为文字列表);材料放入后界面还会**主动提示「可做:X」**(本地分析,不等 AI)。
2. **AI 配方大脑** — 在锻造台/炼金台里用自然语言说"我要一把会喷火的追踪剑",AI(本地 Ollama 或任意 OpenAI 兼容端点)从材料库挑出配方并生成专属法术;AI 不在线时退关键词兜底配方,**游戏永远可玩**。点方案卡放料时自动按序翻存储:玩家背包 → 旅行背包(Traveler's Backpack) → 附近容器(箱子,以及简易储存网络 SSN 的交换接口方块) → 精致储存网络(Refined Storage 2,台子 4 格内的网络);**全部软依赖,装哪个认哪个,不装不崩**;缺的材料会在 actionbar 逐名列出。
3. **自由法术** — 9 元素 × 5 形式 × 5 效果 × 5 修饰的组合法术引擎。九元素各有专属机制(不全是伤害:火点燃、冰霜冻、雷链、自然骨粉/毒、暗影致盲隐身、神圣克亡灵群疗、鲜血吸血换蓝、末影传送漂浮、奥术印记夜视),debuff/utility 九格效果互不重复;单发伤害对标同档武器(power×3.0,模板 power=2×(档位+1))。法杖/魔法书是**增幅器**(法术伤害 +%、法力上限 +X,主手+副手同时生效、效果叠加),不再承载法术;法术本体来自**炼金台**:摆材料或问 AI 炼出魔法卷轴(~26 种模板,含双算子组合技,AI 可生成专属法术) → 右键学习进已学列表 → 按住 B 弹出轮盘,指向扇区松开即施放(点按 B 快速施放上次法术)。
4. **万象森罗** — amplified 奇崛地形的独立维度:虚空矿、微光树、流浪 NPC,以及漫游 Boss **森罗守望者**(传奇材料的主要来源)。
5. **NPC 与烙印** — 流浪相师在主世界五大村庄群系云游(低权重自然刷新),深渊商人出没下界;两位都有真实交易和相反的价值观:相师厌恶屠夫,深渊欣赏强者——你的行为(屠杀/外交烙印)直接影响价格。
6. **修行** — 三轨熟练度:**战斗 / 法术 / 技艺**,全靠行为养成——近战击杀涨战斗、施法涨法术、锻造/炼金/交易涨技艺。升级得点,在 **27 节点技能树**里自由加点(按 O 键打开)。技能树由**流浪相师**开启:找到他**潜行+右键**即可解锁;点错了也能找他**洗点**(10 绿宝石,全部点数返还)。J / 潜行+J 释放主动技(战吼/奥术涌动)。未开启前不攒经验,先找相师是修行第一步。
7. **相谱** — 律二"不可逆铭刻":锻造、击杀、交易全部烙进玩家传记,`/qianxiang saga` 翻阅。**位格**随锻造(+1)与讨伐守望者(+5)提升,进入万象森罗需位格 ≥ 3。

## 快速开始

```bash
./gradlew runClient     # 或双击 start.sh
```

生存流程:拾相材料 → 合成锻造台 → 锻增幅器(法杖/魔法书,开始创作走一段仪式) → 合成炼金台 → 摆料或问 AI 炼卷轴(同样仪式出炉) → 右键学习 → 按住 B 轮盘施法 → 集裂隙精髓 → 右键裂隙岩进万象森罗 → 打守望者 → 传奇材料。成就树(进度 → 千相)全程引导。

测试:`/qianxiang kit` 一键领全套;`/qianxiang dim` 快速往返维度;`/qianxiang shot` 截图(存 run/screenshots)。测试链:kit → 投料锻造增幅器(开始创作→仪式→台面拾取) → 炼金台 AI 卷轴(仪式) → 右键学习 → B 轮盘施法。

键位:**B**=轮盘施法(按住开、松开放)、**O**=技能树、**J**/潜行+J=主动技(战吼/奥术涌动)。键位可在设置里改,默认已避让 Epic Fight(R/K/G/LAlt/Y)。

## AI 配置

`config/qianxiang-ai.json`(首次启动自动生成,游戏内锻造台 AI 设置界面也可改):

```json
{
  "provider": "ollama",              // 或 "openai"(任意兼容端点:LM Studio/DeepSeek/通义…)
  "base_url": "http://localhost:11434",
  "api_key": "",
  "model": "qwen2.5:7b",
  "timeout_seconds": 5
}
```

`/qianxiang ai status` 查看健康度(请求/缓存/失败计数);AI 交互日志在 `logs/qianxiang-ai.jsonl`。

## UGC 生态

不写一行 Java 就能扩展内容,详见 [docs/ugc-ecosystem-guide.md](docs/ugc-ecosystem-guide.md):

- **数据驱动材料** — `data/<ns>/phase_materials/*.json` 给任意物品(含其他 mod)定义相数据,`/reload` 热生效
- **蓝图分享码** — `/qianxiang blueprint export` 生成可粘贴的分享码,好友一键导入
- **服务器工坊** — `/qianxiang workshop publish|list|take` 全服共享蓝图画廊
- **功能/效果 tag** — datapack 或 KubeJS 往 `qianxiang:materials/*` tag 加物品即可参与锻造

## 构建

```bash
./gradlew build         # jar 输出至 build/libs/
./gradlew runServer     # 专用服务端(dev)
```

依赖:Java 21,NeoForge 21.1.219。战斗增强软依赖 [Epic Fight](https://modrinth.com/mod/epic-fight)(纯数据包适配,不装不崩)。
